Leve on Apple Watch.

Storyboard for docs/apple-watch-workout-design.md. Workouts are synthetic. The iPhone stays the only writer. The Watch shows one snapshot and sends ticketed commands, which the phone validates exactly as it validates Live Activity buttons.

Phase 1Smart Stack and rest alert

No Watch app. The existing Live Activity's bannerSmall gets a wrist-sized layout. A local notification at restEnd is forwarded to the Watch while the iPhone is locked.

Phase 2Watch app: the main loop

The Watch app is a remote control. Rest nudges are optimistic and reconciled with the reply. Log waits for the phone's answer.

Phase 2Watch app: edges

States and transitions

Data flow

The Watch surface subscribes to the same frame publisher as the Live Activity. That needs a refactor: tickets are minted today only when an ActivityKit handle exists.
